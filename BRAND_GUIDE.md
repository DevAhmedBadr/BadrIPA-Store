# Badr Store — Brand Guide

## Approved identity

- Product name: **Badr Store**
- Positioning: premium iOS app catalog and distribution experience
- Primary visual direction: black, yellow, and gold
- Tone: premium, clear, modern, trustworthy

## Color palette

| Token | Hex | Usage |
|---|---|---|
| Deep Black | #090909 | Main background |
| Surface Black | #151515 | Cards and panels |
| Signal Yellow | #FFD700 | Primary actions and highlights |
| Premium Gold | #D4AF37 | Premium accents and selected states |
| Champagne | #FFF4CC | Soft gold text on dark surfaces |
| White | #FFFFFF | Main readable text |
| Muted Gray | #A3A3A3 | Secondary text |

## UI rules

- Use Deep Black as the primary canvas.
- Use Signal Yellow for primary buttons and high-priority actions.
- Use Premium Gold sparingly for premium labels, borders, and decorative accents.
- Maintain strong text contrast and accessible focus states.
- Avoid excessive gradients, glow, and ornamental effects.
- Use consistent spacing, rounded cards, and clear hierarchy.
- The interface must remain responsive and optimized for iPhone Safari.

## Product requirements

- Storefront and admin dashboard must share the same design tokens.
- Do not imply that a configuration profile signs or installs IPA files.
- App distribution must use an Apple-compliant signing and distribution method.
- Subscription status and download authorization must be enforced server-side.
